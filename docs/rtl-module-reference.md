# RTL Module Reference

## 1. Scope

This reference covers the 18 synthesizable RTL modules in the active GEMM source set and the generated Xilinx multiplier IP. It intentionally omits testbenches, debug-only modules, generated simulation wrappers, and internal wires that can be read directly from the RTL.

## 3. `GEMM_top`

**Purpose:** Packaged accelerator boundary. Connects AXI4-Lite control, feature/weight AXI4-Stream inputs, result AXI4-Stream output, configuration, and job status.

### Key parameters

| Parameter | Default | Description |
|---|---:|---|
| `P_AXI_LITE_DATA_WIDTH` | 32 | AXI4-Lite data width |
| `P_AXI_LITE_ADDR_WIDTH` | 4 | AXI4-Lite local address width |
| `P_ARRAY_SIZE` | 32 | Array rows, columns, and stream lanes |
| `P_DATA_WIDTH` | 8 | Feature, weight, and result lane width |
| `P_SHIFT_WIDTH` | 10 | Configuration shift width |
| `P_WEIGHT_BUFFER_DEPTH` | 2400 | Input weight memory words |
| `P_FEATURE_BUFFER_DEPTH` | 2400 | Input feature memory words |
| `P_OUTPUT_BUFFER_DEPTH` | 2400 | Output accumulation memory words |
| `P_ACCUM_WIDTH` | 32 | Output accumulation lane width |
| `P_ROW_COUNT_WIDTH` | 9 | M-row register width |
| `P_K_BLOCK_COUNT_WIDTH` | 5 | K-block register width |
| `P_N_BLOCK_COUNT_WIDTH` | 5 | N-block register width |

### External port groups

| Group | Direction | Important signals |
|---|---|---|
| AXI4-Lite | Slave | `S_AXI_A*`, `S_AXI_W*`, `S_AXI_B*`, `S_AXI_AR*`, `S_AXI_R*` |
| Feature AXIS | Slave | `feature_axis_tdata/tstrb/tlast/tvalid/tready` |
| Weight AXIS | Slave | `weight_axis_tdata/tstrb/tlast/tvalid/tready` |
| Result AXIS | Master | `result_axis_tdata/tstrb/tlast/tvalid/tready` |

### Key behavior

- Generates `busy`, `done`, and `idle` status.
- Starts activity on accepted input traffic.
- Completes the job on the final accepted result beat.
- Instantiates the control register file, three stream wrappers, and `GemmAccelerator`.

## 4. `ControlRegisterFile`

**Purpose:** Four-register AXI4-Lite slave for configuration and job status.

### Configuration outputs

| Port | Width | Description |
|---|---:|---|
| `o_cfg_shift` | 10 | Output right-shift setting |
| `o_cfg_row_count` | 9 | Number of output rows |
| `o_cfg_k_block_count` | 5 | Number of 32-element K blocks |
| `o_cfg_n_block_count` | 5 | Number of 32-column N blocks |
| `o_job_start_clear` | 1 | Pulse generated by register 0 bit 16 |

### Status inputs

`i_job_busy`, `i_job_done`, `i_job_idle`, `i_job_clear_accepted`, and `i_job_clear_busy_error` are inserted into register-0 readback.

### Key behavior

- Registers are located at byte offsets `0x00`, `0x04`, `0x08`, and `0x0C`.
- Honors `WSTRB` byte enables.
- Full-word writes are recommended.

## 5. `FeatureStreamSlave`

**Purpose:** Named wrapper for the external feature AXI4-Stream interface.

| Port group | Description |
|---|---|
| External | `feature_axis_tdata/tstrb/tlast/tvalid/tready` |
| Internal | `o_feature_stream_data/valid/last`, `i_feature_stream_ready` |

Instantiates `FeatureAxisFullBeatSlave`.

## 6. `FeatureAxisFullBeatSlave`

**Purpose:** Enforces full 256-bit feature beats and forwards them to the accelerator.

### Key parameter

| Parameter | Default | Description |
|---|---:|---|
| `P_STREAM_DATA_WIDTH` | 256 | Stream data width |

### Key behavior

- `w_full_beat = &S_AXIS_TSTRB`.
- Valid/last are forwarded only for full beats.
- `TREADY` is withheld for a partial beat.
- A sticky internal partial-beat error flag is set for debug.

## 7. `WeightStreamSlave`

**Purpose:** Named wrapper for the external weight AXI4-Stream interface.

| Port group | Description |
|---|---|
| External | `weight_axis_tdata/tstrb/tlast/tvalid/tready` |
| Internal | `o_weight_stream_data/valid/last`, `i_weight_stream_ready` |

Instantiates `WeightAxisFullBeatSlave`.

## 8. `WeightAxisFullBeatSlave`

**Purpose:** Enforces full 256-bit weight beats.

Behavior matches `FeatureAxisFullBeatSlave`, including full-`TSTRB` gating and an internal partial-beat error flag.

## 9. `ResultStreamMaster`

**Purpose:** Named wrapper for the external result AXI4-Stream master.

| Port group | Description |
|---|---|
| Internal | `i_result_stream_data/valid/last`, `o_result_stream_ready` |
| External | `result_axis_tdata/tstrb/tlast/tvalid/tready` |

Instantiates `ResultAxisMasterAdapter`.

## 10. `ResultAxisMasterAdapter`

**Purpose:** Direct AXI4-Stream master adapter for result traffic.

### Key behavior

- Forwards data, valid, last, and ready.
- Drives every result `TSTRB` bit high.
- Supports downstream backpressure.

## 11. `GemmAccelerator`

**Purpose:** Main datapath wrapper and active-configuration register stage.

### Key parameters

`P_ARRAY_SIZE`, `P_DATA_WIDTH`, `P_SHIFT_WIDTH`, three buffer depths, `P_ACCUM_WIDTH`, and dimension widths.

### Main ports

| Port group | Description |
|---|---|
| Configuration | `i_cfg_shift`, `i_cfg_row_count`, `i_cfg_k_block_count`, `i_cfg_n_block_count` |
| Feature input | `i_feature_data/valid/last`, `o_feature_ready` |
| Weight input | `i_weight_data/valid/last`, `o_weight_ready` |
| Result output | `o_result_data/valid/last`, `i_result_ready` |

### Key behavior

- Freezes configuration while an active job is present.
- Instantiates `InputBuffer`, `BufferFeeder`, and `OutputBuffer`.
- Routes `w_compute_partial_last` back to `InputBuffer` and forward to `OutputBuffer`.

## 12. `InputBuffer`

**Purpose:** Stores complete feature and weight streams and replays one K block at a time.

### Key parameters

| Parameter | Default | Description |
|---|---:|---|
| `P_ARRAY_SIZE` | 32 | Lanes per stream beat |
| `P_DATA_WIDTH` | 8 | Lane width |
| `P_WEIGHT_BUFFER_DEPTH` | 2400 | Weight memory words |
| `P_FEATURE_BUFFER_DEPTH` | 2400 | Feature memory words |
| `P_ROW_COUNT_WIDTH` | 10 in module default | Local row-count width |
| `P_K_BLOCK_COUNT_WIDTH` | 5 | K-block count width |
| `P_N_BLOCK_COUNT_WIDTH` | 5 | N-block count width |

### Important ports

| Port | Direction | Description |
|---|---|---|
| `i_compute_partial_last` | Input | Advances the replay sequence after one compute group completes |
| `i_feature_*` | Input/Output | Feature input handshake |
| `i_weight_*` | Input/Output | Weight input handshake |
| `o_buffer_feature_*` | Output/Input | Replayed feature stream to `BufferFeeder` |
| `o_buffer_weight_*` | Output/Input | Replayed weight stream to `BufferFeeder` |

### Key behavior

```text
feature_words_expected = row_count x k_block_count
weight_words_expected  = n_block_count x k_block_count x 32
```

- Readout starts after both input streams are complete.
- Feature replay address is `row x k_block_count + k_block`.
- Input `TLAST` resets the corresponding write pointer.

## 13. `BufferFeeder`

**Purpose:** Working-tile buffer and phase controller between `InputBuffer` and `GemmComputeCore`.

### Key parameters

| Parameter | Default |
|---|---:|
| `P_ARRAY_ROWS` | 32 |
| `P_ARRAY_COLS` | 32 |
| `P_DATA_WIDTH` | 8 |
| `P_ROW_INDEX_WIDTH` | 5 |
| `P_ROW_COUNT_WIDTH` | 10 |
| `P_N_BLOCK_COUNT_WIDTH` | 5 |

### Key ports

| Port group | Description |
|---|---|
| Buffer inputs | Feature/weight data, valid, last, and ready |
| Partial outputs | `o_compute_partial_data/valid/last` |

### Key behavior

- Buffers a feature tile and a weight tile.
- Loads 32 weight words into the compute core.
- Streams feature rows after the weight tile is loaded.
- Repeats across N/K tiles and generates completion markers.

## 14. `GemmComputeCore`

**Purpose:** Weight-load sequencing, feature execution, systolic-array instantiation, and valid/last alignment.

### Key parameters

| Parameter | Default |
|---|---:|
| `P_ARRAY_ROWS` | 32 |
| `P_ARRAY_COLS` | 32 |
| `P_DATA_WIDTH` | 8 |
| `P_ROW_INDEX_WIDTH` | 5 |

### Important ports

| Port | Direction | Description |
|---|---|---|
| `i_load_weight_phase` | Input | Selects weight loading versus feature compute |
| `i_compute_stream_data/valid/last` | Input | Working 256-bit stream |
| `o_weight_tile_loaded` | Output | Indicates 32 weight rows are resident |
| `o_partial_data/valid/last` | Output | Aligned 32-lane partial result |

### Latency constants

```text
LP_MULT_LATENCY        = 1
LP_PE_TOTAL_LATENCY    = 2
LP_RESULT_LATENCY      = 2 x P_ARRAY_ROWS + P_ARRAY_COLS
```

The default 32 x 32 result-valid latency is 96 cycles.

## 15. `ProcessingElementArray`

**Purpose:** Constructs the complete 32 x 32 systolic array.

### Ports

| Port | Width | Description |
|---|---:|---|
| `i_weight_load` | 1 | Loads stationary PE weights |
| `i_feature_vector` | `P_DATA_WIDTH x P_ARRAY_ROWS` | One feature value per array row |
| `i_weight_matrix` | `P_ARRAY_ROWS x P_ARRAY_COLS x P_DATA_WIDTH` | Working weight tile |
| `o_partial_sum_vector` | `P_ARRAY_COLS x 21` by default | Output partial sums |

### Key behavior

- Instantiates one `ProcessingElementRow` per row.
- Skews feature inputs by row.
- Aligns output columns with generated delay registers.

## 16. `ProcessingElementRow`

**Purpose:** Constructs one row of PEs.

- Instantiates one `ProcessingElement` per array column.
- Passes the feature value horizontally.
- Chains partial sums across the configured connections.
- Receives one row of the weight tile.

## 17. `ProcessingElement`

**Purpose:** Signed weight-stationary multiply-add cell.

### Key parameters

| Parameter | Default |
|---|---:|
| `P_DATA_WIDTH` | 8 |
| `P_ARRAY_ROWS` | 32 |
| `P_ARRAY_COLS` | 32 |
| `P_ROW_INDEX_WIDTH` | 5 |

### Ports

| Port | Description |
|---|---|
| `i_weight_load` | Latches `i_weight_value` into the PE |
| `i_feature_value` | Signed INT8 feature input |
| `i_weight_value` | Signed INT8 weight input |
| `i_partial_sum` | Signed incoming partial sum |
| `o_feature_value` | Delayed feature forwarded to the next PE |
| `o_partial_sum` | Product plus delayed incoming partial sum |

Default partial-sum width is 21 bits. The internal multiplier latency is one cycle and total PE latency is two cycles.

## 18. `OutputBuffer`

**Purpose:** Accumulates K-block partial results and emits quantized result beats.

### Key parameters

| Parameter | Typical value |
|---|---:|
| `P_DATA_WIDTH` | 8 |
| `P_OUTPUT_BUFFER_DEPTH` | 2400 |
| `P_ACCUM_WIDTH` | 32 |
| `P_ARRAY_SIZE` | 32 |
| `P_SHIFT_WIDTH` | Connected from top-level shift width |
| `P_ROW_INDEX_WIDTH` | 5 |

### Main ports

| Port group | Description |
|---|---|
| Configuration | shift, row count, K-block count, N-block count |
| Partial input | `i_partial_data/valid/last` |
| Result output | `o_result_data/valid/last`, `i_result_ready` |

### Key behavior

- Sign-extends 21-bit partial sums to 32 bits.
- Uses `SignedAdder` for lane-wise saturating accumulation.
- Starts result output after all K blocks are complete.
- Reads results in row-major / N-block order.
- Instantiates one `RightShifter` per output lane.
- Asserts result `TLAST` on the final beat.

## 19. `SignedAdder`

**Purpose:** Lane-wise signed saturating addition.

### Parameters

| Parameter | Default |
|---|---:|
| `P_ARRAY_SIZE` | 32 |
| `P_DATA_WIDTH` | 8 |

For `OutputBuffer`, `P_DATA_WIDTH` is overridden to 32, producing 32 independent signed 32-bit saturating additions.

## 20. `RightShifter`

**Purpose:** Final requantization from accumulated signed data to the output lane width.

### Parameters

| Parameter | Default |
|---|---:|
| `P_INPUT_WIDTH` | 32 |
| `P_OUTPUT_WIDTH` | 8 |
| `P_SHIFT_WIDTH` | 5 |

### Key behavior

- Arithmetic right shift.
- Uses bit `shift_amount - 1` as a rounding bit when the shift is nonzero.
- Adds one to the shifted value when the rounding bit is set.
- Saturates to the signed output range.
- Handles `shift = 0` using direct saturation.

## 21. Generated `mult_IP`

**Purpose:** Signed multiplier used by every processing element.

| Property | Current configuration |
|---|---|
| Xilinx IP | `mult_gen` |
| A input | Signed 8-bit |
| B input | Signed 8-bit |
| Output | Signed 16-bit |
| Pipeline stages | 1 |
| Generated latency | 1 cycle |

Changing this IP latency requires rechecking the PE and result-valid alignment described in `GemmComputeCore`.
